# 오프라인·직행·업그레이드 전용

출발 DB는 정상 종료된 상태여야 하고(로그 헤더 `is_shutdown`), 도구는 출발 로그·백업 체인을 버리며 도착 DB는 새 로그로 시작한다. 버전쌍은 출발 {10.2, 11.0, 11.2, 11.3, 11.4} → 도착 {11.4, develop}의 **직행**만 지원하고(첫 대상은 11.4 → develop), 중간 버전을 거치는 다단계 이동·다운그레이드·온라인/증분 마이그레이션·HA 환경 전환은 하지 않는다. TDE 암호화 볼륨은 나중에 지원한다 (지도 [workspace#472](https://github.com/xmilex-git/workspace/issues/472) 그릴링 2026-10-29).

엔진에는 버전 사이의 디스크 변환 경로가 하나도 없어(`disk_compatibility_rules[]` 빈 테이블) 중간 버전을 거쳐도 재사용할 단계가 없다. 그래서 다단계 체인 대신 버전쌍마다 직행 규칙(페이지 처리 등급 판정표)을 둔다. 오프라인 전용이 로그 없이 페이지를 직접 쓰는 설계([ADR 0004](0004-no-log-records.md))의 전제다.
